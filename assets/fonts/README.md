# Self-hosted fonts

- CMU Serif Roman, Italic, Bold and BoldItalic WOFF2 files:
  https://github.com/vsalvino/computer-modern/tree/main/fonts
  Retrieved 26 September 2026. License: `CMU-LICENSE.txt`.
- Latin Modern Math OpenType font, version 1.959:
  https://ctan.org/pkg/lm-math
  Retrieved 26 September 2026 from the CTAN `lm-math` archive.
  License: `LM-MATH-LICENSE.txt`; upstream documentation: `LM-MATH-README.txt`.

The exact font files and licenses are committed with the site. The website makes
no requests to a font CDN. Computer Modern Unicode and Latin Modern Math are
distinct Computer Modern-derived families, used for prose and MathML respectively.
